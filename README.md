# API организационной структуры Hitalent

Реализация ТЗ [TASK.md](./TASK.md) на FastAPI + PostgreSQL + Docker.  
Позволяет управлять деревом подразделений и сотрудниками с валидацией бизнес-правил.

## Возможности
- Создание/обновление/удаление подразделений (каскадное или с переназначением).
- Создание сотрудников в подразделениях.
- Получение дерева подразделений с настраиваемой глубиной (depth 1..5) и опциональными сотрудниками.
- Защита от циклических ссылок в дереве.
- Уникальность имени подразделения в пределах одного родителя.
- Автоматические миграции через Alembic.
- Документация OpenAPI (доступна по `/docs`).
